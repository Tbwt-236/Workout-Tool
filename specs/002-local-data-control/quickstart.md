# Quickstart and Validation: 本地数据说明与 JSON 导出

**Updated**: 2026-10-14 | **Status**: 已有真实App实现，Android原生部分验收完成

[Spec](spec.md) · [Tasks](tasks.md) · [Evidence](verification.md)

## 运行

在`apps/mobile`使用Node24及锁定依赖。`npm run test:ci`、`npm run typecheck`、`CI=1 EXPO_NO_TELEMETRY=1 npm run lint`核验代码；`npm start`启动开发宿主。实际手机需与当前Expo运行环境兼容；构建通过不等于手机已更新。本轮Android测试包见verification，不是iPhone安装包或商店版。

只用合成数据。进入「历史→数据」；0场可看说明但导出灰色。有已完成训练后点击「导出」，由系统选择保存/分享路径，结束后仍在面板。勿将返回理解为保存收据，应在实际接收位置读取JSON确认。

## 验收场景

| 编号 | 操作与检查 |
| --- | --- |
| Q-001 | 空/有历史及进行中训练打开数据、切中英、展开/关闭；次数重量原始输入、月份和选日不变；没有接受状态或训练门禁 |
| Q-002 | 空历史按钮禁用；跨日/同日、Unicode/引号、无组动作、null/整数重量导出逐字段核对；仅全量已完成，坏聚合整体失败 |
| Q-003 | 1000场/4000动作/20000组完整性；20轮保存/删除交错，文件对应单快照；分开记录快照/编码/写文件/系统等待耗时和大小 |
| Q-004 | 取消系统选择、保存到支持的本地接收路径、重新导出、分享不可用/调用失败；在接收处读取JSON；返回不显示“保存成功”，不立即删已交接文件 |
| Q-005 | 快照/写入/交接前关闭或后台，迟到结果不分享；关闭期间进详情等待读取；分享后后台/返回不重复；连点只一任务 |
| Q-006 | 写入中、move前后、系统调用前后终止进程，重启不自动分享；缓存消失/删除失败/过期受控文件/未来mtime，保护训练库、未知文件及用户副本；24小时不是读完证明 |
| Q-007 | 当前构建实际权限/备份资格与恢复分开记录；中英320宽、大字号、键盘、读屏和iOS Modal分享叠层实际操作 |
| Q-008 | 数据流审查与5名目标用户合成数据找入口/解释副本；至少4名30秒内完成。额外同意义务按实际法域/平台审查，不自动增加弹窗 |
