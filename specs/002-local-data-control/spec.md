## User Scenarios & Testing *(mandatory)*

### User Story 1 - 随时理解数据用途与控制方式 (Priority: P1)

作为匿名使用者，我希望随时知道 App 保存哪些训练内容、为何保存，以及如何删除或取出，以便自主决定如何使用。

**Why this priority**: 承接宪章的数据用途说明、数据控制路径及采集/分享前审查要求。宪章没有指定必须采用阻断式同意弹窗，本草案不将未研究的法律必要性写成产品机制。

**Independent Test**: 在空历史、有历史和训练进行中打开说明，切换语言后返回，检查说明可达且现有输入、训练及日历位置不变。

**Acceptance Scenarios**:

1. **Given** 空历史或已有历史，**When** 用户打开获批入口，**Then** 能查看字段、用途、本地存储、既有删除路径、导出及副本限制。
2. **Given** 训练含已录组和未提交输入，**When** 查看说明、切换语言或返回，**Then** 不清空草稿、不替用户保存或取消，也不改变日历浏览位置。
3. **Given** 用户关闭说明，**When** 返回训练，**Then** 不新增记录许可状态、不阻断既有 001 流程，也不把关闭解释为法律同意。

### User Story 2 - 主动取出完整的已完成训练 (Priority: P2)

作为有本地历史的用户，我希望主动导出一份可阅读的文件，以便自行保管；即使不再继续记录，也能取出既有数据。

**Why this priority**: 让数据控制有实际出口，不把“在本机保存”等同于用户能够取走数据。

**Independent Test**: 用空历史、跨日、同日多场、空重量和中文名称夹具导出，解析并逐项与同一快照比较。

**Acceptance Scenarios**:

1. **Given** 用户看到“全部已完成训练、明文文件”的范围说明，**When** 点击“导出全部训练”，**Then** 生成完整文件后直接进入系统保存/分享选择；该次点击是发起动作，默认不增加第二次确认或待分享页面。
2. **Given** 某组未记录重量，**When** 导出，**Then** 保留 null 和明确单位，不解释为 0 公斤或徒手。
3. **Given** 无已完成训练，**When** 导出，**Then** 生成合法空集合并显示 0 场，不把空历史当故障。
4. **Given** 保存或删除与导出交错，**When** 文件生成，**Then** 对应一个一致数据库快照，无半场、部分组或混合时点。
5. **Given** 当前仍有训练草稿，**When** 导出，**Then** 仅包含已完成历史，不导出或改写草稿、原始输入及说明阅读状态。

### User Story 3 - 中断、取消与返回不会损坏记录 (Priority: P3)

作为用户，我希望取消或离开导出流程时原记录仍在，并能区分本地文件生成、系统流程打开和接收方保存。

**Independent Test**: 注入快照、写文件、分享和清理失败；交错重复点击、离页、前后台、进程终止及迟到回调，检查训练不变、单任务锁可恢复、文件不被错误分享或清理。

**Acceptance Scenarios**:

1. **Given** 读取或文件生成失败，**When** 结束，**Then** 不分享部分文件、不显示成功，原记录不变，可显式重试。
2. **Given** 尚未调用系统分享，**When** 用户离开导出所属页面或应用进入后台，**Then** 取消本次继续分享意图；迟到结果不得打开系统界面，受控文件进入清理流程。
3. **Given** 已将文件交给系统，**When** 应用退后台、返回或收到回调，**Then** 不以返回或 Promise 完成推断接收方保存，也不自动再次分享；保护仍可能被系统使用的文件。
4. **Given** 同次任务正在处理，**When** 连续点击，**Then** 不产生并行任务或第二个系统界面。任务终结后，新的显式请求可以开始。
5. **Given** 进程在任一步终止，**When** 再启动，**Then** 不恢复自动分享或遗留内存锁；按受控清单及专属目录核对残留文件，不触及训练库或用户自行保存的副本。

### Edge Cases

- 损坏聚合导致整个导出失败，不能静默跳过并声称完整。
- 仓储 Busy 明确提示重试，不以空数组降级；快照事务在编码/文件/分享前释放。
- 名称中的换行、引号、反斜杠和 Unicode 可往返；切语言不翻译用户内容或 JSON 字段。
- 磁盘不足、清单写入失败、文件提交前后中断、分享不可用及清理失败都有恢复路径，不把部分文件当完整文件。
- 创建文件前先持久化归属；分享调用前先持久化“可能交给系统”标记。中断后无法证明尚未分享的文件按未知交接状态处理。
- 旧任务回调只处理本任务资源，不能触发分享、覆盖新任务或释放新任务锁。
- 时钟回拨或异常跳变不能单独作为安全清理证明。
- 接收方可能把明文文件发送给云服务或他人；应用内删除不撤回已交出的副本。
- 系统备份尚未核实，不能写“数据绝不离开设备”。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 提供简体中文与英文数据说明，列明字段、记录/回顾用途、本地存储、单条删除、导出及副本限制，不要求账号。
- **FR-002**: 实施和真实试用前完成产品数据流与同意审查；实际法域或平台是否另需用户同意机制须研究后独立决定。本草案不宣称法律结论，也不实现记录许可状态机。
- **FR-003**: 查看、关闭说明及导出不得改变 001 开始/编辑/完成语义，不新增选择数据库表、训练门禁或撤回清空草稿行为。
- **FR-004**: 获批入口复用现有训练/历史导航，不加第三个底部标签；空历史仍可查看说明及导出。
- **FR-005**: 导出须由用户主动点击，事先清楚说明全部已完成历史与明文范围；不含草稿、原始输入、内部诊断或说明阅读轨迹。
- **FR-006**: 候选输出为含格式版本、生成时间及快照时点的 UTF-8 JSON，不要求联网、账号或付费。
- **FR-007**: 保留 UTC 开始/完成时间、时长、名称、动作/组顺序、次数及明确单位的重量；null 原义不变，不翻译用户内容。
- **FR-008**: 导出来自单一一致性快照；保存/删除交错时无混合数据；损坏数据明确失败而非省略。
- **FR-009**: 空历史导出合法空集合，并显示 0 场。
- **FR-010**: 完整文件生成后，由本次显式请求直接进入系统选择；未完成、已取消或所属页面不再有效时不得打开系统流程，不预设接收方或自动发送。
- **FR-011**: 同时仅一个活动导出任务；重复操作返回 Busy，任务终结必须释放对应锁；旧回调不能覆盖新任务、释放新锁或再次分享。
- **FR-012**: 交给系统前离页/后台取消继续分享意图；交给系统后按可证结果收尾并保护文件。进程重启只恢复清理，不自动恢复导出或分享。具体状态见契约。
- **FR-013**: 分别表达生成、可证打开、可证取消、结果未知及失败；无可靠平台证据不得声称接收方保存成功。
- **FR-014**: 文件及清单仅在专属命名空间；先登记归属再写文件，完整提交后才可分享。启动时核对清单与文件、处理部分文件和孤儿状态，不跟随目录外链接，不触及训练库或用户副本。
- **FR-015**: 安全点已证实的临时文件尽快清理；未知交接状态的“24 小时”仅为未核实的候选清理资格阈值，不是实际保留上限。只有平台安全条件与阈值同时满足，才在下次启动/前台执行清理；失败或时钟异常保持待清理。实施前须核实并确认策略，不以未知安全条件默许无限保留。
- **FR-016**: 当前语言故障反馈可重试，不输出 SQL、路径、训练正文或堆栈；诊断仅记录必要状态、计数、耗时及文件大小。
- **FR-017**: 新操作满足平台触摸/读屏要求；语言切换、离页、取消、导出及返回均保持训练与日历位置，不以静态测试代替设备验收。

### Key Entities *(include if feature involves data)*

- **数据说明**：当前 App 的用途与控制方式文案，不保存每位用户的阅读或接受轨迹。
- **训练导出快照**：确定数据库状态的不可变已完成记录集合。
- **导出任务与临时文件**：任务标识、任务状态、文件归属、可证交接状态及待清理状态。

## Success Criteria *(mandatory)*

- **SC-001**: 空历史/已有历史/进行中训练的说明和导出流程均可达；关闭、切语言、取消和失败用例中，原训练及输入 100% 保持不变。
- **SC-002**: 空集合及 1000 场夹具全部字段与快照一致；规模固定为每场 4 动作、每动作 5 组，即 4000 动作/20000 组，无遗漏或额外草稿。
- **SC-003**: 20 次保存/删除与导出交错中，每份文件都对应单一快照，系统分享不占用数据库事务。
- **SC-004**: 重复点击、离页、前后台、进程中断、迟到回调及四类故障均无重复分享、锁泄漏、错误清理或虚假送达。
- **SC-005**: 5 名目标用户中至少 4 名在 30 秒内找到导出入口，并能指出接收方可能把文件带离设备；仅用合成数据。
- **SC-006**: 中英、320 宽、键盘及读屏下完成说明→导出→取消/返回；关键操作和反馈可识别，返回路径不被遮挡。

## Assumptions

- 全部需求仍待评审；001 的三轮批准不等于新增界面已批准。入口 A/B 问题已发出，尚无用户答复。
- 不增加账号、云、AI、付费、第三标签、全量删除、导入恢复、加密归档、自动备份、统计 SDK 或分享追踪。
- 当前数据说明加显式导出是产品最小提案；是否存在额外用户同意义务须按实际数据流和平台另行研究/批准，不通过本文件自行认定。
- 001 T030 的真实数据使用条件保持原状；未满足前只用合成数据。没有运行时同意弹窗不等于该闸门被取消。
- 24 小时清理资格阈值尚未核实；应用未运行、文件可能仍被使用、清理失败或时钟异常时，实际残留可能更久。最终文案与实现须反映核实后的行为。
