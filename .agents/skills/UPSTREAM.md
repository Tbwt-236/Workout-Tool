# Quality skills provenance

These project-local skills are derived from selected workflows in
[`obra/superpowers`](https://github.com/obra/superpowers), MIT licensed.

Selected upstream skills:

- `test-driven-development`
- `systematic-debugging`
- `verification-before-completion`
- `requesting-code-review`

Imported for this project on 2026-07-28. The local versions are intentionally
self-contained and adapted to the FitQuest Spec Kit + Expo workflow. The full
Superpowers plugin is not installed, because its planning and execution
workflows overlap with Spec Kit.

When updating these files, compare the upstream `SKILL.md` and referenced
resources, document meaningful differences, and keep the four responsibilities
separate: test-first implementation, root-cause diagnosis, fresh verification,
and independent review.
